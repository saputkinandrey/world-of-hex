# Literary Decision Encoders: локальный результат

Проверка 25 октября 2026 года: Windows, RTX 3060 Laptop 6 ГБ, Python 3.12.9,
PyTorch 2.8.0+cu128, Transformers 5.5.4, Sentence Transformers 5.4.1, FP32.
Все три checkpoint скачаны с закреплёнными ревизиями вне Git. Две модели
работают на CUDA; для третьей установлена конкретная ошибка публикации.

Задержка измерена для одного запроса с тремя действиями на каждом языке после
отдельного прогрева. Это небольшая диагностика, а не устойчивый рейтинг скорости.
Пики разных фаз не обязаны возрастать монотонно. CUDA-значения отражают выделения
PyTorch, включая веса, но не всю память драйвера. Также сохранены reserved-пики,
device-wide free/total, RSS с шагом 10 мс и lifetime peak RSS. Полная проверка
обучения включает вычисление признаков, хеширование весов и проверки сохранения;
её RAM-пики выше, чем при запросах: около 3714,8 и 2416,3 MiB соответственно.

## Ошибка Literary MiniLM

Штатный `SentenceTransformer` возвращает `ValueError: Unrecognized model ...
Should have a model_type key in its config.json`. В корне закреплённой ревизии
нет `config.json` и `modules.json`; конфигурация BERT и manifest помещены внутрь
`1_Pooling`, причём там отсутствует корректная конфигурация pooling-модуля.
Базовые веса вместо литературных не подставлялись; структура checkpoint и
контекст не изменялись. Для продолжения нужен исправленный checkpoint автора
либо отдельное решение о явно документированном восстановлении упаковки.

Опубликованный токенизатор доступен: общий короткий набор занимает 69–71 токен
на английском и 66–69 на русском. Таким образом, входы целиком помещаются в
заявленные 128 токенов. Это не подтверждает работоспособность энкодера.

## Выводы и следующий этап

1. Для дальнейших русскоязычных технических экспериментов сейчас удобнее
   **ruELECTRA**: меньше энкодер и потребление CUDA, заявлен русский язык,
   проверены замороженные веса и независимые головы. Для английской литературной
   адаптации доступна FABLE. Это выбор по технической пригодности, не по качеству
   моделирования характера.
2. Контекст 128/512 ограничивает полноту биографии и обстоятельств. NER, поиск
   сходных фрагментов и RTD не обучают выбору поступков. Доля художественной
   литературы во всей истории обучения неизвестна. Обработка русского текста
   FABLE не доказывает понимания русского языка.
3. У FABLE и ruELECTRA обе головы прошли по 12 шагов на двух явно искусственных
   примерах с разным количеством действий. Потери конечны, параметры голов
   изменились; полный SHA256 энкодеров не изменился, градиентов у них нет.
   Обучение второй головы не изменило первую. Повторная загрузка первой головы
   дала побитово одинаковые оценки. Проверены перестановки по ID и явный отказ
   на слишком длинном входе. Неразмеченные сценарии не использовались для обучения.
4. Для настоящего обучения нужны размеченные эпизоды с информацией, доступной
   персонажу в момент выбора, допустимыми альтернативами, фактическим действием,
   источником/произведением/сценой и правами на данные. Нужна независимая проверка
   с разделением по сценам/произведениям и универсальные базовые энкодеры для
   проверки самой гипотезы о пользе литературной адаптации.

Качество решений NPC и переноса характера не оценивалось. Полноценное обучение
на литературных поступках не запускалось. Старый Character Decisions не изменён.
