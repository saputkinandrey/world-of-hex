## 1. Действия, потребности и трешхолды

Есть тип `ActionDefinition` (см. from-gpt/action-definition.ts). Важные моменты:

- У действия обязательно есть `tag`, соответствующий `ActionTags` / `*ActionTag` из `action-tags.ts`.
- У действия **может быть** поле `needThresholds?: Partial<Record<NeedTag, NeedGate>>`.
- Тип трешхолдов мы используем такой:

```ts
export enum NeedThresholdEnum {
  WARN = 'WARN',
  IMPAIRED = 'IMPAIRED',
  SEVERE = 'SEVERE',
  CRITICAL = 'CRITICAL',
}

export interface NeedGate {
  atLeast?: NeedThresholdEnum;
  atMost?: NeedThresholdEnum;
}
semantics:

atLeast — действие доступно только если текущая зона дефицита этой потребности ≥ указанного порога.

atMost — действие недоступно, если зона дефицита > указанного порога.

Оценка зоны идёт по порогам warn / impaired / severe / critical из NeedThresholds (см. needs.ts). Ниже warn считаем «нормой» без зоны.

Пример (важно, чтобы ты так же мыслил дальше):

ts
Копировать код
export const EAT_ACCEPTABLE: ActionDefinition = {
  tag: FoodActionTag.EAT_ACCEPTABLE,
  needThresholds: {
    FOOD: { atLeast: NeedThresholdEnum.IMPAIRED }, // «нормальная» еда с среднего голода
  },
};

export const EAT_POOR: ActionDefinition = {
  tag: FoodActionTag.EAT_POOR,
  needThresholds: {
    FOOD: { atLeast: NeedThresholdEnum.SEVERE }, // плохая еда только при сильном голоде
  },
};

export const EAT_ANYTHING: ActionDefinition = {
  tag: FoodActionTag.EAT_ANYTHING,
  needThresholds: {
    FOOD: { atLeast: NeedThresholdEnum.CRITICAL }, // всё подряд только на критическом голоде
  },
};
Важное правило:

Для разных ступеней качества/риска мы заводим разные действия, а не один экшен с параметрами по зонам.

Приоритизацией действий (какое именно выбрать) займёмся отдельно, не надо лепить внутрь потребностей «скоры», actionScore и т.п.

Ещё моменты по стилю:

НЕЛЬЗЯ добавлять export default словари вида const XxxByTag = Object.fromEntries(...) — WebStorm на них ругается и отваливаются тайпхинты. Можно экспортировать массивы (FoodActions: ActionDefinition[]) и именованные константы (export const FORAGE = {...}), но без default словаря по тегу.

export function getLessSleepLevelFromMorphs(morphIds: readonly MorphId[]): number {
	let level = 0;

	}

 *  hours = baseHours - LessSleepLevel
