# Архив проекта ChatGPT «World Of Hex»

Снимок источников проекта ChatGPT, сделанный 2026-08-26.

## Состав

- `catalog.json` — полный каталог 78 разговоров с устойчивыми идентификаторами и ссылками на оригиналы.
- `chats/` — выгрузка сообщений каждого разговора в JSON.
- `project-source-inventory.json` — перечень файлов и внутренних источников, прикреплённых к проекту ChatGPT.
- `wiki-candidates.md` — очередь тем, которые можно переносить в человеко-читаемую вики после проверки.
- `review-status.json` — состояние содержательной проверки каждого разговора.
- `user-statements/` — производный слой только из реплик пользователя.
- `scripts/build-user-statements.mjs` — повторная сборка производного слоя.
- `scripts/verify-archive.mjs` — проверка полноты и связей архива.

## Правила доверия

1. Реплики пользователя являются первичным свидетельством авторского решения, но поздние реплики могут отменять ранние.
2. Ответы ChatGPT считаются предложениями, пока пользователь явно не подтвердил их или они не закреплены в актуальном коде либо вики.
3. Исправления пользователя имеют приоритет над всеми предшествующими формулировками.
4. Технические исследования и внешние факты требуют повторной проверки перед переносом в канон.
5. Архив разговора — источник, а не готовая статья вики.

## Ограничения выгрузки

Интерфейс чтения возвращает не более десяти ходов за страницу и не более 20 000 символов на отдельное сообщение. Вложения в разговорах фиксируются по имени, но их временные пути не считаются переносимыми источниками. Отдельные прикреплённые файлы перечислены в инвентаре; содержимое недоступных файлов не восстанавливается по догадкам.
