# Кандидаты на перенос в вики

Подготовлено по полному архиву из 78 разговоров проекта ChatGPT «World Of Hex». Ссылки ниже ведут на слой пользовательских реплик; полные диалоги лежат рядом в `chats/`.

## Принцип переноса

Разговор не переносится в вики целиком. Для каждой темы нужно:

1. собрать позднейшие утверждения пользователя;
2. найти отменённые и конфликтующие формулировки;
3. сверить результат с действующей вики и кодом;
4. перенести только устойчивое содержание;
5. записать происхождение и конфликт в журнал импорта.

## Проектная документация

Для вики пет-проекта стоит создать отдельный верхнеуровневый раздел, например `development/`, не смешанный с `canon/`:

- архитектура обмена данными: P2P, gRPC, WebRTC, MCP и распределённое хранение;
- устройство RPS-модуля и помощника ведущего;
- пайплайн тайлов, heightmap, Photopea, Godot и браузерной сборки;
- правила работы с источниками и импорта;
- технические решения экономики и производственных цепочек.

Технические разговоры описывают как принятые решения, так и исследованные альтернативы. В документацию следует переносить только текущий выбор; альтернативы можно сохранять в ADR или разделе истории решений.

## Оставить только в архиве

Переводы, разовые исправления кода, общие вопросы по инструментам, временные рекомендации по хостингу и разговоры без принятого проектного решения уже доступны для поиска в архиве. Их не следует превращать в страницы вики, пока не появится конкретная потребность.
