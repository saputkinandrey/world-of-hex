# План проверки головы SW

1. Сверить исходный кадр и bicubic-вход с успешным снимком; сохранить хеши и параметры.
2. Параметризовать существующие воркеры, сохранив численные значения обычного запуска.
3. Выполнить ровно десять новых пар LayerDiff/SemanticSam с заданными seed; сохранить всю серию отдельно от current.
4. По сохранённым данным сравнить пороги, компоненты, маски в исходных координатах, IoU и анатомическую правдоподобность.
5. Проверить независимый вклад SemanticSam и создать увеличенные атласы и карты различий.
6. Создать исполняемый skill 0.1, проверить интерфейс, провести ревью и сделать один общий коммит.
