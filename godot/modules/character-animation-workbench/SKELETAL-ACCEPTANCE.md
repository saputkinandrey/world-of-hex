# Приёмка v1.1: деформация цельных модулей

Дата: 2026-10-21. Движок: Godot 4.7.2 stable Steam, Windows / OpenGL
Compatibility, NVIDIA RTX 3060 Laptop. Проект объявляет 4.6; отдельного
прогона бинарником 4.6 не было. API сверены с официальной документацией 4.6.

## Сначала проверенный вертикальный срез

До расширения стенда создана и отрендерена сцена с одним **цельным кадром
исходного тела**: Polygon2D, 529 вершин, 968 треугольников, 12 Bone2D,
сохранённый AnimationPlayer-клип с ключами 0 / 1 / 2 s. На t=0.5 s получается
автоматическая промежуточная деформация. Исходное изображение не разрезалось.

Умеренный наклон Spine 0.12 rad, Chest 0.04 rad и сгиб ForearmL 0.18 rad
дали видимую деформацию без заметных разрывов в просмотренных кадрах.
Это основание продолжить работу с мягкими движениями, **не доказательство
приемлемости большого замаха**. Затем к тому же скелету подключены рубашка,
брюки, обувь и остальные присутствующие модули; отрендерены два цвета рубашки.

Минимальная сцена: `tests/deformation-proof.tscn`, запуск F6.
Основная сцена: `skeletal-animation-workbench.tscn`.
Рендер доказательства: `run.ps1 deformation`.
Результаты: `tmp/animation-workbench/deformation/`:

- `body/frame-*.png`: цельное тело, 60 кадров 512x512 при 30 FPS;
- `white/frame-*.png`, `blue/frame-*.png`: те же ключи с двумя рубашками;
- `skeletal-deformation.gif`, `skeletal-deformation.mp4`: три варианта рядом;
- `mesh-overlay.png`, `workbench.png`: сетка, кости и интерфейс.

Перед кодированием проверены все 180 кадров: полная нумерация, одинаковый
размер, видимый персонаж без обрезки, 59 изменяющихся кадров в каждом клипе.
Просмотрены покой, промежуточный кадр, максимум деформации и overlay.
Тест также проверяет изменение расстояний **внутри** поверхности при
неизменных Base.transform и polygon: это не поворот/масштаб всего PNG.

Разница нейтральной растеризации относительно Sprite2D (из 1,048,576 каналов
RGBA в каждом изображении 512x512):

| Вид | Изменённых каналов | Максимальная разница |
| --- | ---: | ---: |
| South | 0 | 0/255 |
| North | 59 | 1/255 |
| SouthWest / SouthEast | 251 | 1/255 |
| NorthWest / NorthEast | 240 | 2/255 |

Расхождения малы и связаны с растеризацией текстурированных треугольников.
Они не выдаются за побайтовое совпадение. Максимальная допустимая разница
в автоматическом сравнении — 2/255; геометрическая регистрация не подгоняется.

Дополнительно проверены:

- отражение X-траектории кости ровно один раз и сохранение Y;
- отдельные RESET position/rotation/scale по авторским ракурсам;
- Stop и смена комплекта исполняют **отредактированные ключи RESET**;
- ручные UV-правки переживают смену атласного кадра и повторное открытие;
- ручные веса переживают смену комплекта и повторное открытие;
- несовместимое смещение слоя не исправляется скрытой коррекцией;
- остальные исходные позы отклоняются без подстановки Idle-картинок.

## Границы результата

Подготовлены Idle-риги четырёх авторских ракурсов и их два отражения.
Другие нарисованные исходные позы требуют своих проверенных шаблонов;
они не получают случайно веса Idle. Автоматический морфинг разных PNG,
большой убедительный боевой замах и клип с несколькими нарисованными
якорными позами не заявляются. Оружие имеет независимый pivot; его контакт
с рукой аниматор задаёт отдельно. Для больших амплитуд существующие пиксели
могут растягиваться и менять перекрытия; скрытые детали не реконструируются.

Итог отличается от v1.0 поведением: теперь деформируется внутренняя
поверхность цельных изображений, а цветовые варианты одежды используют
один набор ключей и не требуют отдельного анатомического разбиения/рисовки.

## Файлы

- `skeletal-animation-workbench.tscn`, `skeletal-workbench.gd`: новый основной стенд;
- `skinned-rig.gd`, `skin-surface.gd`, `skin-overlay.gd`: snapshot binding, UV и диагностика;
- `rigs/*-rig.tscn`, `rigs/*-surface-*.tscn`: явные кости и редактируемые шаблоны;
- `animations/rig_lean.tres`, `rig_reset_*.tres`, `skeletal-library*.tres`: native-клипы;
- `tests/skeletal-acceptance.*`, `deformation-proof.tscn`, `proof-preview.gd`,
  `render-deformation.gd`: проверки и доказательство;
- `run.ps1`, README и SKELETAL-документы: команды, инструкция и отчёт.

Сцена и клипы v1.0 сохранены для сравнения. Старый compatibility workbench,
его ресурсы настройки и CharacterSpriteEntity не изменялись.
