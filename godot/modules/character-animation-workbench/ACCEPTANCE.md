# Приёмка Sprite Animation Workbench v1.0.0

Проверено 2026-10-21 на Windows, Godot 4.7.2 stable Steam, OpenGL Compatibility,
NVIDIA RTX 3060 Laptop. В `project.godot` указана версия 4.6; отдельный прогон
движком 4.6 не выполнялся. Использованы штатные API AnimationPlayer,
AnimationLibrary и @tool, документированные для 4.6.

## Результаты

| Сценарий | Статус | Свидетельство |
| --- | --- | --- |
| Исходный стенд и компоновщик неизменны | done | `git diff --exit-code -- godot/modules/character-sprite-tool godot/modules/character-sprite godot/project.godot`; обычный headless-запуск исходной сцены |
| Нейтральная композиция | done | Проверка всех присутствующих слоёв: текстура, кадр, позиция, масштаб, эффективный flip, видимость и z; побайтовое сравнение RGBA двух SubViewport в OpenGL для фронта, неполной диагонали и отражения, а также полного дополнительного комплекта |
| Интерполяция | done | Реальный AnimationPlayer: угол -0.45 в ключе 0.2 s, угол 0.2 и позиция (3.5, -1) между ключами в 0.325 s; второй независимый контроллер тоже движется |
| Независимость базы и центра вращения | done | Motion не изменяет Base; загрузка источника не удаляет треки; изменение Pivot Offset сохраняет нейтральный global_transform изображения |
| Переиспользование | done | После смены рубашки та же траектория оружия и число треков; источник перезагружается отдельно от клипов |
| Зеркало | done | Отражённые X-смещения имеют противоположный знак, Y совпадает, handedness преобразования меняется; пиксельное совпадение с исходным восточным направлением |
| Сохранение | done | Оба клипа загружены отдельным чтением с диска; сцена с изменённым Pivot Offset сохранена, загружена и инстанцирована заново; pivot и треки сохранены; тесты также запускаются отдельными процессами |
| Граничные случаи | done | Отсутствующие слои диагностируются и не сохраняют stale texture; неподдерживаемая сабля в longarm скрыта, без замены мушкетом; смена источника останавливает и сбрасывает движение |
| Парсинг и запуск нового модуля | done | Headless-приёмка, графическая приёмка и отдельный запуск сцены без ошибок нового модуля |
| Полный импорт существующего проекта | partial | Команда выполнена; импорту мешают ранее существовавшие встроенные скрипты `res://scenes/ship.tscn`: `class_name isn't allowed in built-in scripts` |

`tests/acceptance.gd` выполняет проверки настоящего рига и компоновщика.
Графический прогон дополнительно сохраняет игнорируемые `neutral-*.png`
и `workbench-preview.png`; изображения просмотрены. Ошибка недоступного
`user://`-кеша в песочнице устранена запуском графической проверки с доступом
к локальному каталогу Godot; финальная графическая приёмка проходит без неё.

Ограничения проверки: интерактивное ручное добавление ключа мышью в нижней
панели Godot и закрытие/повторное открытие окна редактора человеком не
выполнялись. Вместо этого проверены сохранённые native-ресурсы, повторное
чтение файлов, сохранение/инстанцирование сцены, реальные интерполяция и рендер.
Качество боевой хореографии для остальных ракурсов не заявляется.

## Созданные файлы

- `character-animation-workbench.tscn`, `character-animation-workbench.gd`: сцена,
  2D-preview, источник, диагностика и простая панель F6.
- `module-pivot.gd`: независимый центр вращения с компенсацией.
- `source-adapter.gd`, `import-source.gd`: чтение исходной композиции и импорт.
- `source-settings.tres`, `base-catalog.tres`: выбранные наборы и их снимки.
- `animations/*.tres`: библиотека, RESET и два демонстрационных клипа.
- `tests/acceptance.gd`, `tests/acceptance.tscn`, `tests/.gitignore`: приёмка.
- `run.ps1`: фиксированные команды импорта и проверок.
- `README.md`, `ACCEPTANCE.md`, `.gd.uid`: инструкция, отчёт и Godot UID.

Старые `character-sprite-tool.*`, `character-sprite.entity.gd`, сцена
`character-sprite.tscn`, исходные рисунки и `project.godot` не изменены.
