# Rigging & Keyframe Animation Editor v1.0.0

Отдельный локальный редактор Character1 в существующем Godot-проекте. Деформация выполняется Skeleton2D/Bone2D/Polygon2D, время задает AnimationPlayer, изображения экспортируются из SubViewport через GPU.

## Запуск

Из корня репозитория:

```powershell
.\godot\modules\character-rigging-editor\run.ps1 editor
```

Для запуска сразу с общей зацикленной демонстрацией замените `editor` на `demo`.

Используется существующий `_tools/godot-workbench/godot.exe`; другой движок можно указать через `GODOT_BIN`. Python нужен только подготовке данных и анализу; используется существующий `experiments/anatomy-benchmark-v1.0.0/.venv`.

## Работа

В дереве выберите позу или переход. Четыре режима: Rig Setup, Pose Preview, Transition Editing, Sequence Preview.

- Колесо: 2/4/8/16/32x; средняя кнопка: панорамирование; левая: выбор и перемещение сустава.
- Rig Setup меняет bind/rest выбранной KeyPose. Справа доступны координаты, угол, длина, регистрация, z-порядок и сила двухпиксельной мягкой зоны. Reset возвращает исходные сустав, угол и длину выбранной кости.
- Transition Editing: Play/Pause, Stop, начало/конец, шаг 30/60 FPS, скорость, длительность и перемотка. Числа на timeline означают секунды; расписание переключений задано нормированным временем 0..1. Blend Duration тоже нормирована на длительность перехода.
- Add key добавляет состояние в текущем времени. Перемещение/поворот кости внутри перехода также создает или обновляет ключ. Конечные состояния редактируются через KeyPose в Rig Setup.
- Золотые ромбы обозначают ключи, фиолетовые линии — смену текстуры. Промежуточный ромб можно перетаскивать; фиолетовая линия меняет whole-pose switch либо выбранную часть. Ключ также можно выбрать в списке и переместить кнопкой Move selected key here.
- Whole pose / Per part: задайте момент переключения, Blend Enabled и Blend Duration. В режиме Per part сначала выберите кость. Нулевая длительность означает мгновенный switch.
- Sequence Preview показывает Idle → Walk → Aim → Walk → Idle → Aim → Idle. Both/SW/NW позволяет увеличить один ракурс. Время общее, позы и ресурсы ракурсов независимы.
- Show Texture Sources: Idle синий, Walk оранжевый, Aim зеленый. Это только диагностика. Также доступны анатомия, сетка, кости, границы, швы и исходное изображение поверх деформации.
- Save all changes сохраняет измененные ресурсы. При смене ресурса или закрытии окна редактор предлагает сохранить изменения. Cancel оставляет текущий ресурс и правки. Смена режима сама по себе ключи не переписывает.

## Данные

`poses/{direction}/{pose}.json` — отдельные KeyPose со своими суставами, inverse bind, геометрией, UV, весами, источником анатомии и регистрацией. `assets/` содержит точные копии пяти исходных цветов и неизмененные owner-карты. `transitions/` содержит 12 независимых направленных ресурсов без копирования геометрии. `sequences/demo.json` задает порядок и общие интервалы.

При подготовке читается только принятая (`Accepted`) ручная разметка из настоящего каталога Mask Editor. Проверяются подпись исходников, путь и SHA256 архива, signed override-карты. `Corrected`, тестовые cache-workspace и непринятые правки не подмешиваются. В отсутствие принятой правки используется Flood Fill. Все шесть текущих ресурсов используют Flood Fill.

Обычный `prepare-e` сохраняет существующие KeyPose и добавляет только отсутствующие. При изменении исходных масок он явно останавливается. Для намеренной повторной генерации с заменой собственных правок нужен `tools/prepare.py --stage E --rebuild`; предварительно сохраните отредактированные JSON.

## Проверки и экспорт

```powershell
.\godot\modules\character-rigging-editor\run.ps1 test
.\godot\modules\character-rigging-editor\run.ps1 export
.\godot\modules\character-rigging-editor\run.ps1 diagnostics
```

`exports/south-west/` и `exports/north-west/`: по шесть последовательностей, 150x150, 30 FPS, по 31 кадру с обеими конечными точками. `exports/comparison/`: 300x150, 181 кадр. `frames.json` хранит суставы, углы, корень (Pelvis) и доли источников по чанкам. PNG имеют прозрачный фон.

`run.ps1 video` проверяет полный набор PNG и создает дополнительный MP4 1200x600 с целочисленным nearest увеличением, 30 FPS, 6 секунд. У MP4 черный фон; прозрачность остается в PNG. Существующий видеофайл не перезаписывается.

Все сцены и узлы заданы в `.tscn`; runtime-фабрик узлов нет. Редактор запускается из исходного локального проекта, отдельный распространяемый executable/PCK в этот эксперимент не входит.

## Известные ограничения

Суставы — начальные оценки по анатомии, требующие настройки оператором. Старые SW Idle координаты L/R противоречат DensePose; новый модуль сохраняет прямое соответствие Left → ArmL и Right → ArmR, используя собственные координаты для всех поз. Старый риг не менялся.

В NW Idle нет групп Right Upper Leg / Right Lower Leg / Right Foot. `initial-anchors.json` явно задает стартовые точки отсутствующих суставных областей по существующей NW-калибровке; маски и отсутствующая геометрия не достраиваются. Правая нога может двигаться как ошибочно классифицированный Torso. Панель показывает NO ANATOMICAL GEOMETRY для пустого чанка.

Смена исходной текстуры оставляет скачки контура, промежуточная деформация — разрывы и растяжение. Crossfade может давать двоение и снижение альфы в перекрытии. Сглаживания, дорисовки и автоматического исправления анатомии нет. См. `REPORT_v1.0.0.md` и `MEASUREMENTS.md`.
