# План реализации v1.0.0

1. A: отдельная статическая сцена Godot, Idle/SW, суставы, сохранение, zoom/pan. Проверить запуск и roundtrip.
2. B: независимые bind/rest и native-texel поверхности Idle/SW и Aim/SW. Проверить исходный RGBA через GPU.
3. C: общий скелетный кадр, деформация обеих текстур, whole/part switch. Сохранить первый переход и измерения.
4. D: Walk/SW, шесть независимых переходов, timeline, промежуточные ключи и последовательность.
5. E: три самостоятельные позы NW и шесть переходов.
6. F: синхронный просмотр SW/NW, экспорт 30 FPS, автоматические проверки и отдельный визуальный отчет.

Все изменения ограничены новым модулем. Старые эксперименты, изображения, риги и клипы не редактируются. Python используется только для чтения масок и подготовки геометрии; деформация и растеризация выполняются Godot. Узлы заданы явно в tscn. Принятые ручные исправления читаются без создания Store и без записи в редактор масок.
