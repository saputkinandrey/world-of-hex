# План парного редактирования SOMA

1. Проверить канонические 77 имён и родительские связи. Явно задать пары,
   включая глаза, руки/ноги и все оригинальные суставы пальцев.
2. Добавить локальный обработчик только команды Apply joint parameter.
   Существующие проекция/FK, камеры, якоря и данные калибровок не изменять.
3. Вычислять относительный edit до изменения любой стороны. Переносить его
   через текущие родительские/суставные ориентации в анатомическую систему
   корня. Зеркальная плоскость определяется canonical bind, а не камерой.
4. Для Rotation использовать quaternion delta и отражение матрицы поворота.
   Inverted использует обратный зеркальный delta. Для Length переносить
   отношение фактических длин; в линзе сохранять существующий Offset Override.
   Невозможную положительную длину отклонять явно и атомарно.
5. Добавить Free/Symmetric/Inverted, выделение обеих сторон и предпросмотр
   длин. Режим хранить отдельной настройкой редактора, не в скелете/линзах.
6. Проверить A–M в Godot, включая асимметричные позы/локальные оси, пальцы,
   Working NorthWest и связанный NorthEast. Получить реальные снимки трёх
   режимов в шести проекциях. Тестовые правки сохранять отдельно от Working.
