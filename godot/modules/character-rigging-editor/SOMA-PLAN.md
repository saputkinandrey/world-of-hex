# План SOMA Calibration

1. A: подключить неизменяемые источники, стандартные 77 суставов SOMA,
   происхождение масок, явные соответствия и диагностику качества.
2. B: получить первый результат Character1 / Idle / South из интервальных
   ограничений чанков; записать адаптивный порядок размещения.
3. C: выполнить совместную робастную подгонку, добавить статический интерфейс
   существующего редактора и отдельное сохранение ручных исправлений.
4. D: сравнить другие South-позы после подгонки позы с базовой геометрией.
5. E: сравнить авторские ракурсы после подгонки проекции общей геометрии.
6. F: допускать накопление только при подтверждённом соответствии и регистрации;
   не объявлять неопределённую глубину или изменение длины измеренным фактом.
7. Проверить математические инварианты, сохранение исправлений, интерфейс
   и регрессии прежнего редактора. Зафиксировать ограничения в отчёте.

Исходные PNG, маски, старые KeyPose, переходы, Workbench и MotionBricks
остаются источниками только для чтения. Commit/push не выполняются.
